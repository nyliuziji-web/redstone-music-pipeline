# 原创夜间短作：窗外月迹

独立冷启动 agent 从 brief 创作的 40 秒短曲，非学习曲的变调或复制。MIDI、作品结构、四槽原创合成声音 spec、建筑与演出提案均保留在本目录，以 CC0-1.0 提供。没有外部采样或商用原曲。评测经过与干预见 [冷启动审计](../../docs/COLD_START_REPORT.md)。

在生产依赖环境执行 `build-soundpack examples/night-study/sound_spec.json --out projects/night-bank` 生成实际样本与 profile；用 master.mid 初始化新作品。按照各专业 Skill 的任务合同导入 profile + resources.zip、stage_module.json 与 show_score.json，再 run。CLI 前缀为 `python run_pipeline.py`。

建筑以当前实体模板的世界坐标编写；换布局先重新预览保护与构图。visuals 会将 show namespace/sampleKey 对齐实际机器时钟。提供的音色与动作是创作候选，不能视作用户已认可、实际游戏已播放或完成录制。
