# mcbuild offline integration

The package uses the pinned upstream `VoxelGrid` implementation to enforce sparse-grid capacity and extent limits. Its SHA-256 and commit are recorded in [provenance.json](provenance.json); [LICENSE](LICENSE) retains the upstream MIT notice.

`redstone_music.stage_tools` adds a data-only blueprint adapter, musical-machine protection, and a simple-color multi-view CPU renderer. No imports or arbitrary Python from a blueprint are executed. Minecraft textures, blockstates, hosted model orchestration and the NeoForge live-building mod are excluded.

The preview is for shape and clearance review, not redstone simulation, lighting validation or proof of final in-game appearance.
