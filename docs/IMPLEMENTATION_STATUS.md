## 0.3.0a2 当前状态

集成包已具备从可信 MIDI 构建 **可玩的红石音乐候选** 的主链。八个 Skill、任务交接、素材校对、音符盒编配、声音包、实体机器、视觉数据和交付验证都已进入同一包。艺术判断与成片仍是独立工作，尤其依赖素材质量、真实游戏和听看反馈。

本版把[轻声部织体试法](../skills/music-director/references/guide.md#轻声部织体试法)接入音乐导演 Skill，并提供可离线运行的 [texture-study](../examples/texture-study/README.md)。原创 16 秒练习的基线有 80 个起音，织体版附加 26 个，二者同刻起音峰值都是 4。两版复用同一声音包，提供同增益混合及新增层独奏，输出可独立构建的工程。Windows 的暂存目录发布现在会对短暂的占用错误有限重试。

Windows 本地测试 118 项，117 通过，依赖私有 Nevada 素材的 1 项跳过。两套原创织体项目均完成六阶段构建。较早的 GitHub CI 通过记录见下文。新版本以这次本地测试和独立安装的结果为准。

真实曲目技术验证采用局部样段。保留了原编曲的 238 个起音、位置和采样字节，另加 56 个轻声起音，同刻峰值仍是 5。原版实录中新增层独奏比基线混合低约 19 dB，整段混合的 RMS 差约 0.07 dB。这验证了弱声部可单独播放且总体增益稳定。艺术偏好仍由听审决定。公开包使用原创练习，原曲、录音、私有作品和本机运行环境留在本地。

**当前最值得优先补足的三项**是混音到可信分轨谱的校对效率、当前视觉版本的完整实机验收，以及可移植的录制与成片流程。

## 0.3.0a1 音乐能力升级

2026-11-19。面向只拿到录音、只有可靠旋律、需要游戏配器三种起点。

- 音频候选使用独立解释器运行。Basic Pitch 保存原始模型输出和 MIDI。Beat This! 输出节拍及强拍。audio-separator 分人声与伴奏，已实测 CPU 下载首次运行和缓存离线运行。原曲与候选保留同一零点，试听报告标出末音、时长差和候选之间有分歧的位置。转写后端的使用方法见[本机音频后端](../integrations/transcription/README.md)。
- 编曲工具保留源 MIDI、踏板、速度和冻结主题，支持限域修订、增加声部和导出。采用固定提交的 music-skill 和弦进行助手。在原创 16 小节上实跑两种伴奏，均用 FluidSynth 2.6.2 与 GeneralUser GS 渲染了混合与独奏，并使用 FFmpeg 生成等响度比较。
- 音符盒的默认适配以整条声部为单位统一槽位。原创 20 秒练习制作了三组不同音体、可独立调整的声音槽、25 格校准和同一采样的长音对照。MIDI 61–82 的旋律由根音 72 的单槽覆盖，零八度偏移。额外音符盒模组未列入默认环境。
- Windows 本地自动测试 117 项，116 通过，1 个需私有 Nevada 素材的回归跳过。测试包含实际 Basic Pitch ONNX 和 Beat This! CPU 推理。已完成的测试不替代用户听审。
- 全新环境只安装 wheel 和普通生产依赖，成功读取自带 Skill、调用固定版本和弦连接助手并完成 8 秒 demo。另从 `--reference-audio` 新建项目，使用原创已知谱走音乐任务交付，导入七槽声音包，完成六阶段构建与交付 ZIP 检查。该测试验证导入与构建，转写质量由独立实验评价。

在有真值的 20 秒原创素材中，干净主旋律的 80 音里有 79 音被 Basic Pitch 命中。混音直接转写得到 197 音，其中 121 音能与已知的 130 个有音高源音一对一匹配。两项均按同音高、起音相差不超过 50 ms 统计。混音候选还需要清除多报和补齐漏音。真实歌曲的 30 秒样段已生成原录音、旧谱、混音直转和分出人声后转写的试听。缺少准确对照谱和听审结论。

本版试听为离线 GM 和采样近似，仍需用户反馈与实际游戏验证。MuScriptor 接口需要另配授权权重，本轮未实测。只给混音时，默认先通过样段决定转写与重编的比例。
