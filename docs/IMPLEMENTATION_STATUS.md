# 0.2 开发预览实施与验证

2026-11-17。这里记录实际完成度；[改写方案](REWRITE_PLAN.md)是目标，不是完成证明。

## 已实现

- 8 个自有专业 Skill 与渐进教程，START_HERE、需求/计划/反馈模板、固定提交的 Minecraft 技能参考。
- 音乐检查、music21/librosa 分析、Mido 严格局部编辑、SwiftF0 单旋律候选；按乐句的显式音符盒适配、采样声音包与实际频谱校准；三种试听和 FFmpeg 等响对比。
- 36 秒原创学习曲，314 音，包含速度变化/控制事件/分段/长音，错八度、共享声音槽、错误根音与建筑保护练习。
- 受限声部布局/相机参数、建筑预览和保护合入、show score、标准 Fabric 参照客户端；独立环境元数据导入、Photon 确切发行检查与同段实验准备。
- 类型化文件任务、嵌套采样指纹、决策记录、绑定候选字节的反馈与过期检查、交接、实际媒体检查/截取、wheel/源码包资源。

## 实际验证

干净的 Python 3.12.16 独立环境安装 production / pitch / dev；实际 numpy、NBT、MIDI、SoundFile、music21、SciPy、TinySoundFont 小操作通过；librosa、SwiftF0、FFmpeg 在测试中处理原创音频。GM 只有引擎测试，尚无选定的发行 SoundFont。

首轮统一测试：85 项，84 通过、1 项私有 Nevada 素材回归按预期跳过。新增媒体/冷启动回归的最终数量以仓库 CI 和发布记录为准。源码 wheel 已实际构建；最终隔离安装记录另行更新。

独立新 agent 未继承开发对话，仅读取公共工作包，原创《窗外月迹》：12 小节、72 BPM、40 秒、56 源音、四个原创声音槽、零移调；15,558 世界方块含 512 装饰方块，73 个演出动作。正式任务导入与六阶段构建到 candidate_ready，Anvil/Litematica 独立回读、ZIP CRC 通过。详细[冷启动审计](COLD_START_REPORT.md)。

冷启动曾需要维护者修复合法 namespace 连字符被视觉校验拒绝的问题；因此本次不称为“初版零干预通过”。另发现单模块跨度限制和全景预览可读性问题，已补教程/结构化错误路线。
