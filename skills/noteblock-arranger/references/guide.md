# 从MIDI到游戏表达

## 先确定整条声部的音色

比较声部音域、起音速度、持续、频谱和角色。不让旋律跨一个阈值就从harp突然换flute，除非这是有意配器。优先整句移调、拆高低采样区、换统一音色或调整织体；每种做法明确改变什么。

所有移调、合并、删除或新增持续层都记录来源。移调母版与游戏层是不同决定；音符盒音域不应静默修改原始母版。

`plan-noteblocks` 和新建项目默认 `role`。同一角色用同槽、同八度偏移。MIDI 61–82 的旋律可以用 MIDI 72 为根音的单音覆盖，得到 note 1–22。若超过 24 半音，选择按明确乐句分区、显式适配或重写需要适配的声部后试听。允许按间隔先提出分句候选时加 `--consistency phrase`。最终方案可用 `--adaptation-plan FILE` 重放，检查每个源音的去向。

## 持续音策略

| 场景 | 候选策略 | 必须听的风险 |
|---|---|---|
| 短拨弦/打击 | 自然衰减 | 尾音与快速复音是否糊 |
| 主旋律长音 | 持续样本、少量补触发或明确持续层 | 重触发起音颤动、旋律是否被盖住 |
| 和声铺底 | 稀疏持续层、分解或局部补触发 | 低频/中频堆积、尾音跨和声 |
| 角色交接 | 保留呼吸与清晰起音 | 旧角色尾音遮盖新主读 |

补触发间隔应根据样本实际包络、变速后的长度和乐句决定，不把某首作品5/6GT经验套到所有音色。增加补触发还增加机器规模和同时发声数，需记录代价。

默认没有测量过包络的原版档使用自然衰减。用 `timbre-study` 比较同一声音样本在自然衰减和按实测包络补触发时的差异，再用 `audit-palette` 看高音缩尾与低音越界。只有继续旧工程的逐音选色和固定间隔时，才显式设置 `sound.adapter: legacy-vanilla`。

## 统一时序

tempo map积分为绝对秒，非负值统一`floor(seconds*20+0.5)`。普通中继器是2GT，本包1GT精度来自已验证相位模块。不要为外部NBS示例自动降成10TPS，也不要逐间隔取整累积。

视觉只将真实源起音作为单音爆发；补触发服务声音持续，不能每次都炸一次粒子。切片开始时的承接音标`carry`，保留源结束时刻。

## 工具闭环

```shell
python run_pipeline.py plan-noteblocks input.mid --out work/adaptation
python run_pipeline.py plan-noteblocks input.mid --out work/custom-adaptation --profile work/sounds/profile.json
python run_pipeline.py render-preview work/custom-adaptation/events.json --out work/noteblock.wav --mode noteblock --profile work/sounds/profile.json
```

读取工具返回的实际路径和报告字段。声音profile不是只有显示名称：需要可解析样本路径、根音、角色槽、基底与持续策略。自定义包改变中心音时，重新测实际频率；服务器note数字相同不代表听到同一音高。

## 成功与失败练习

使用`learn`原创曲与基础profile，先生成适配，再比较母版与采样渲染。报告主题是否换音色、持续处理是否增添起音、哪种力度被近似以及长音的机器成本。

故意让主旋律和pad共用一个槽并降低其增益。通过同增益独奏与混合，证明两者联动；提出独立槽位的修复，并同步profile/样本/基底/事件。不要把弱旋律单独归一化后声称混音已修好。

## 退出条件

源音去向完整，无未声明折八度；每个声音槽与样本可解释，量化与原时序差异可测。关键代表段有实际采样或游戏试听，空间近似清楚标注，最后以移动跟拍录音复核。
