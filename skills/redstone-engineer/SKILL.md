# 实体机器工程

从冻结事件与布局合同工作，保护来源音高、起音、onset/retrigger/carry。编译器生成候选，独立回读与真实服务端追踪验证结果。

按[机制与实测教程](references/guide.md)先测一个音、和弦、相邻1GT、长音补触发及停止重播，再扩规模。相机、灯、视觉读取同一音乐时钟，但各有启动/插值语义。

保留已验证的奇偶相位模块；新模块或布局先做局部机制测试。普通中继器最小2GT，不通过改期望或降精度掩盖误差。

不在游戏运行时离线修改其存档；测试在独立副本，只管理本任务进程。依赖由profile与实际JAR元数据确定，不能直接复制旧机器私有classpath。

完成交付世界、投影、控制包、事件/布局/容量说明、逐音日志与停止/重播/保存重进范围。客户端画面/音频由实际回放另验，失败按电路、加载、相机或声音分别返回。
