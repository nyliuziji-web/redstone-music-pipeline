# 轨道与场景设计

先写要看的主读、观看距离、相机路线与风格词，再做少量模块，不先生成几千格装饰。轨道本体的比例、层级、节点节奏和休止可见性优先于纯数量。

读[模块设计教程](references/guide.md)。用蓝图/体素工具生成多视角候选，检查音符盒上方空气、声音基底、导电邻域和相机通道；冲突时修改或拒绝整个模块。

需要设计可进入的建筑、街面或聚落时，走[Minecraft 建筑模块](../../docs/MINECRAFT_ARCHITECTURE.md)。先取真实尺度和风格参考，规划走路与跟拍两套视线，再离线构件、带状态组装、进游戏验收。

固定照明服务休止和结构阅读，同步灯服务音乐起音。发光材质、光影辉光和照亮邻近结构是不同能力，最终用实际机位与目标光影比较。

交付风格/比例依据、参数化模块与部署规则、保护检查、预览和客户端对照。独立大型建筑按作品范围启用；不把局部预览成功说成整条轨道或完整红石验证。
