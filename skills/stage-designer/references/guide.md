# 模块、比例与视线

从已有演奏谱做一段完整场景，参照[从乐句到轨道、建筑与稳镜头](../../../docs/PHRASE_TO_WORLD.md)的布轨、建筑合入、碰撞练习和关键帧实例。

## 先确定观看问题

中央跟拍时，最近的音符盒和模块可能比远景大很多。先画截面，标出主读、镜头高度、左右层级、未来路径和字幕安全区。主题、伴奏与低频可以有不同的结构节奏，但不让每层都有同样密度的装饰抢主读。

用一个灯座、肋架、栏杆或拱架试比例，确认完整后再重复布置。大跨度构件可在乐句/段落边界变化；均匀模板铺满全曲很难产生发展。

## 蓝图和预览

```shell
python run_pipeline.py preview-stage examples/stage_module.json --out work/stage-preview
python run_pipeline.py preview-stage examples/stage_conflict.json --out work/stage-rejected
```

蓝图采用工具支持的声明式几何原语；具体shape与字段以学习样例/schema为准，不能把任意Python脚本当蓝图。查看四方向/俯视的PNG及材料统计，再从实际相机路径看近处、远处和侧面。

`schemaVersion:1`的`operations`支持`set`、`fill`、`frame`、`stairs`：set用`pos`，fill/frame用`min/max`，stairs用`origin/steps/direction`，方块用完整namespaced state。也可直接列`blocks:[{pos,block}]`。外部`--protection`或蓝图内的`protection`包含保护boxes、noteBlocks、circuitBlocks/circuitClearance和cameraPath。

故意失败例仍会渲染候选，结果的`accepted:false`及冲突报告表示不能安装；不能只看命令退出0或有PNG就当通过。

CPU简色预览用于几何/构图，不模拟完整光照、红石、流体、重力或Fabric效果。真实物理与画面在最终环境验证。

## 保护与安装

保护对象包括原音乐块、音色基底、音符盒上方空气、红石连接邻域、加载/控制装置和相机视线。air删除也属于写操作，应检查是否清掉机器；旋转楼梯、门和半砖时状态必须同步。

整体模块的拒绝原因应可读。删除几个碰撞方块后留下残缺半个模块通常不是合格设计；返回修改比例、位置或形状。

## 光影和材质

代表段的音轨和粒子定下来后，按[音轨场景收尾与 Nevada 画面配置](../../../docs/SCENE_FINISH_AND_LOOK.md)整理贴轨装饰、两侧地形和远景，并做原版与外观配置对照。

先比较白天/夜间或同机位有无目标光影，查休止时结构是否可读。需要固定灯时建立可复用光源节点，不靠增加粒子掩盖黑暗。画面偏白可能是辉光/曝光与透明叠加，不一定缺颜色。

为材质/光影记录版本和设置。预览器自带资源与MC资源有独立许可，公开包使用原创简色资源或操作者本地提供的资源。

## 成功与失败练习

以原创蓝图做一个带楼梯/半砖/玻璃的框架，保存四视图，检查朝向、空隙和重复接缝。把同模块放入保护区，工具应拒绝并说明原因；调整后仍需全曲独立回读与真实事件核对。

在实际相机机位比较两种宽度，选择不遮住核心声部且近远都有轮廓的版本。只凭俯视图对称不能证明跟拍构图成立。

## 退出条件

当前单个蓝图限 50,000 方块、2,000 操作、每轴跨度 512 格。长轨道先做单模块近景，再按可接受跨度分批设计。全景按整条轨道缩放，不能代替单模块四视图。合入机器使用世界绝对坐标；已占位置、线路两格邻域、音符盒基座/头顶与相机通道均受保护。合入只接受被动稳定装饰；仍需真实物理与光影检查。

模块完整、状态正确、保护检查通过，布置规则与相机关系明确。新增装饰前后音乐事件完全一致，保存重进/真实运行与目标光影检查有记录。
